# 产品终点与当前状态

> 更新：2026-09-02。决策依据见 [DECISIONS_2026-09-02.md](./DECISIONS_2026-09-02.md)。

## 0. 产品终点（先读这半页）

**用户是谁**：外部创作者，通过我们托管的 SaaS 使用，多租户按 `org_id` 隔离。
不是自托管，不是 ComfyUI 面板，不是给自己用的内部工具。

**输入是什么**：一部小说的原文，或一句话/一段创意（可附参考内容）。

**终点是什么（M2）**：项目内每个镜头都能产出一条**带配音的 MP4**，
可单镜下载、可批量下载全部镜头。用户拿到逐镜 MP4 后，自己决定在平台上拼接
（后续版本）还是去剪映。

**中间经过什么**：

```
小说 / 创意
  → 情节目录 + 分集大纲
  → 剧本                                    【确认】
  → 角色档案 → 场景档案（各自出基准图）
  → 分镜（集 → 镜；含时长、台词、提示词）    【确认】
  → 每镜首帧图（多候选 + 当前版）
  → 每镜配音（TTS，得到真实时长）
  → 每镜视频（镜内按模型单段上限切段，段拼成镜）
  → 每镜 MP4（段拼接 + 配音混音）
  → 下载
```

**用户能选什么**：每个能力（文本 / 图像 / 视频 / TTS）用哪个模型。
组织默认 → 项目覆盖 → 生成前临时选，生成前选择是界面上的按钮。
可以用平台 Key 扣 Credits，也可以自带 Key 打折。

**明确不做（M2 内）**：整集时间线、字幕、BGM、转场、剪映导出、支付、团队成员、
运营后台、合规审核、自建 GPU / ComfyUI、Skill 运行时、节点画布、角色实体化、图片编辑。
读到"给用户用"不要去做支付，读到"视频"不要去做时间线。

## 3. 当前优势（改造中别弄丢）

- 模块化单体，`tasks.status` 是执行状态唯一真相（ADR-008）。
- 账务不可变流水、reserve/settle/release、幂等键、行锁。
- `org_id` 隔离，跨租户一律 404。
- Capability / Provider / Runtime 三层分离，failover 与熔断在 Gateway。
- Agent / Skill 只能是 YAML，白名单校验。
- 一致性引擎：风格锁定、提示词合成由后端统一，Agent 不写风格词。
- 三道人工确认门，串行过门——比 ReelBench 的并行迭代更可靠。

## 4. 当前主要问题

### 4.1 产品没有到成片

分镜图之后没有视频、配音、合成、下载。这是唯一要变绿的尺子。

### 4.2 两套前端壳并存（已决定：freeflow 替换，ADR-030）

`(app)` 与 `/freeflow` 并存。freeflow 审批要跳回旧页、故事/分镜编辑只存组件本地、
任务页读 `agent_runs` 不读 `tasks`、素材页不能上传、悬浮助手只回本地预设。
ADR-030 定了替换的唯一前置条件：freeflow 能独立跑完"新建 → 剧本确认 → 分镜确认 → 出图"。

### 4.3 设计目标与代码事实混杂

`video.generate`、`audio.tts`、`timeline.render` 任务类型、前端 `AssetKind` 里的
video/audio/export 都只是**预留**，不计入功能。文档里统一用"预留"标注。

### 4.4 工程收口不足

- 大量未提交修改横跨前后端、迁移、测试（`content` 模块、ADR-029、`project_docs/`）。
- ESLint 9 flat config 未完成，前端 lint 门禁不可用。
- GitHub Actions 只跑后端；前端 `typecheck + build` 未进 CI（决定加，见 §8 开发流程）。
- Docker Compose 只面向开发；无生产镜像、无告警、无恢复演练。
- 部分 freeflow 组件是单行 JSX。

### 4.5 两棵文档树（本轮解决）

`aigc_studio_docs/` 与 `project_docs/` 曾各写一份。自本轮起 `project_docs/` 是唯一入口，
ADR 留在 `aigc_studio_docs/15`，其余旧文档标"历史"。

## 6. 悬着的事

2026-09-02 文档重写时 Worker 从代码里核出的、比文档更严重的事（详见 `orca/tasks/W1.report.md`、`W2.report.md`）：

- **`POST /credits/topup` 没有权限判定**，任何登录用户可给自己加 Credits。Wave 0 修。
- **文本链路 `advance` 全程不建任务、不预扣、不结算、不幂等**，`agent_runs.cost` 恒为 0，熔断对主链路文本生成无效。Wave 1 修。
- **出图预扣按默认模型估价**：payload 不带 `model_id`，项目偏好选了贵模型也按便宜的预扣（违反 ADR-024 硬约束 1）。Wave 1 修。
- **一致性实际只到 L0**：`ImageRequest` 没有参考图字段；`score_shot` / `lock_style` 没有调用方，风格从未真正冻结，废片率永远测不出。
- **镜像里没有 ffmpeg**；`pricing._shape` 没有视频 / TTS 分支，接上后会按一张图的价预扣。

- **真实废片率仍未测出**。`pricing_rules.image_retry_factor = 250` 是拍值，不可对外报价。
- `base_portrait_asset_id` / `base_reference_asset_id` 两列 AI 出图成功后从不回写，
  "AI 生成"那条路只体现在 `tasks` 上。候选版本（ADR-033）落地时一并解决。
- 文本生成链路曾经不传 `org_id` 到 Gateway，BYOK 租户实际走平台 Key。
  `feat/freeflow-prototype` 已修，合并前要确认这条修复在里面。
- Docker 未运行时无法跑迁移和测试，`content` 模块的收口卡在这里。
