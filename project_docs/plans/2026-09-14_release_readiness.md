# 交付与上线准备

日期：2026-09-14。负责人授权 Lead 持续开发并把关交付质量，默认在 main 开发。
当前基线 a9e8cf4 是阶段快照，不是可上线版本。产品终点沿用逐镜带配音 MP4；
视频时长与候选版本以 ADR-034/035 为准，不能直接照抄已被覆盖的旧媒体草案。

## 推进顺序与验收门

| 顺序 | 范围 | 验收证据 |
|---|---|---|
| 1 | A/B/C 提示词生产链路、生成记录、工作台 | 生产 API 路径测试，跨租户/过期/失败/幂等测试，整轮浏览器验证；区分 Mock 与真实生成 |
| 2 | 资金与身份边界 | 管理员发额度权限与审计；文本推理预扣/结算/释放及幂等；实际模型与估价一致；账号恢复和生成权限 |
| 3 | 首帧、配音、视频、逐镜 MP4、下载 | 依 ADR-034/035 先固定模型约束与候选版本契约，再贯通任务/账务/资产/UI；真实产物验证 |
| 4 | 部署、运维与发布演练 | 可重建镜像与配置校验、迁移/回滚、健康检查、备份恢复、错误和成本监测；部署候选经演练后再申请生产发布 |

每个实施任务写清文件所有权、输入输出、失败语义、验收与禁止事项。
Worker 自报完成不算验收；Lead 复核实际改动和结果后更新状态。
后续功能不能绕过尚未解决的权限、计费、数据隔离缺陷。

## 资源与操作约束

- 本机 16 GB 内存、四核 CPU，2026-09-14 检查可用内存约 5–6 GB，C 盘余 4.2 GB。
  一次最多一个实施 Worker；构建、浏览器和数据库检查串行，复用既有依赖。
- 数据库验收复用带独立名称和归属标记的测试库、Redis 与对象存储桶。
  不对用户作品自动重跑，不修改部署检出或生产数据。
- 真实模型验收前明确对象与次数。实际生产发布在可审查候选和演练完成后确认。
- 当前仍未实现视频、TTS、MP4；支付、字幕、BGM、整集时间线等维持既有范围决定。

## 本轮已确认的发布阻碍

- 提示词新增 Agent 缺 eval 与生产路径回归测试，后端前轮已交接。
- 浏览器旧全绿汇总与较新的失败用例并存，必须整轮重验。
- `POST /credits/topup` 当前只有登录依赖，没有管理员判定；公开运营前必须收口。
- 当前后端镜像没有 ffmpeg；视频/音频任务类型仍是预留。
- 媒体模块文档仍有已被 ADR-034/035 覆盖的方案，实施前先修订契约。

后续状态与具体证据记入 `00_CURRENT_STATUS.md` 和相应模块文档。
